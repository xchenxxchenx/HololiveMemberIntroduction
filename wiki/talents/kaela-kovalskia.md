# 卡埃拉·科瓦爾斯基亞 (Kaela Kovalskia / カエラ・コヴァルスキア)

> 「GSH! Get Some Help! Kaela here.」

[[kaela-kovalskia|卡埃拉·科瓦爾斯基亞]]是隸屬於 Hololive ID 的虛擬藝人（VTuber），所屬期別為 [[id-3rd|3rd Generation (HoloH3ro)]]。

---

## 1. 簡介與背景

Hololive ID 3期生，繼承偉大工匠衣缽的帥氣鐵匠少女，全社乃至全球直播界的「爆肝肝帝第一人」。 於 2022-03-26 正式展開活動。動輒連續直播 15~30 小時不眠不休、在 Minecraft 中單人挖穿伺服器建造奇蹟級材料庫、冷面笑匠無聲笑聲。

---

## 2. 外貌與衣裝特徵

由繪師 **ヤスダスズヒト** 擔綱設計，Twitter / 社群標誌符號為 🔨。立繪圖檔存放在 `asset/picture/hololive/Kaela-Kovalskia_list_thumb.png`。在各項 3D 與重大官方企劃中皆展現出極富辨識度的代表形象。

---
