# 薇絲緹雅·潔塔 (Vestia Zeta / ベスティア・ゼータ)

> 「Mission start! Secret agent Vestia Zeta here!」

[[vestia-zeta|薇絲緹雅·潔塔]]是隸屬於 Hololive ID 的虛擬藝人（VTuber），所屬期別為 [[id-3rd|3rd Generation (HoloH3ro)]]。

---

## 1. 簡介與背景

Hololive ID 3期生，秘密組織代號「V.7」的特務少女，堅稱自己是特工而非貓咪的呆萌特務。 於 2022-03-25 正式展開活動。軟萌甜美的聲線、執行任務時屢屢出包的廢柴呆萌反差、極其可愛的貓耳髮型。

---

## 2. 外貌與衣裝特徵

由繪師 **あるてら** 擔綱設計，Twitter / 社群標誌符號為 📜。立繪圖檔存放在 `asset/picture/hololive/Vestia-Zeta_list_thumb.png`。在各項 3D 與重大官方企劃中皆展現出極富辨識度的代表形象。

---

## 3. 直播特色與代表風格

軟萌甜美的聲線、執行任務時屢屢出包的廢柴呆萌反差、極其可愛的貓耳髮型。
- **粉絲社群**：粉絲統稱為「Zecretary」，直播間互動熱絡，社群向心力極強。
