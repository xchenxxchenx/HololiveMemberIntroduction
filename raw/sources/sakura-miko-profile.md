# 【原始資料】櫻巫女 (Sakura Miko) 官方檔案與活動歷程摘錄

- 資料來源：Hololive Production 官方網站及公開資料庫

## 1. 基本資訊
- 姓名：さくらみこ (Sakura Miko / 櫻巫女)
- 所屬：Hololive JP - 0th Generation
- 狀態：active (出道日：2018-08-01)
- 粉絲名：35P (Mikopi)
- 繪師：田中雄一 / おるだん
- 標誌符號：🌸

## 2. 標誌特色與簡述
Hololive 0期生，自稱「菁英巫女（Elite Miko）」，Hololive 頂尖綜藝與社內大企劃發起人。
獨特的嬰兒音口音與綜藝體質、深受遊戲之神眷顧的戲劇性意外（熔岩事故）、對美少女與工口遊戲情有獨鍾。

## 3. 人際關係與搭檔
與 [[hoshimachi-suisei|星街彗星]] 組成超人氣商業夥伴組合 [[micomet|MiComet]]；與 [[shirakami-fubuki|白上吹雪]] 等組成遊戲王決鬥夥伴。

## 4. 代表梗與重要記憶
「Stay Home!」（GTA 經典台詞）、熔岩桶自焚傳奇、經典嬰兒咬舌日語。
